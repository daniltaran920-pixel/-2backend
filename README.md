# E-Commerce REST API Backend

Мощный и безопасный RESTful API бэкенд для магазина товаров, написанный на **Node.js** с использованием веб-фреймворка **Express** и построителя запросов **Knex.js** для работы с базой данных **PostgreSQL**.

В проекте реализована полноценная система авторизации (аутентификации) и разграничения прав доступа на основе ролей (**RBAC**), защищающая операции с базой данных от несанкционированного доступа.

## 🚀 Технологический стек
* **Node.js** — программная платформа для выполнения JavaScript на сервере
* **Express.js** — минималистичный и гибкий веб-фреймворк для обработки маршрутов
* **Knex.js** — гибкий query builder для безопасного построения SQL-запросов к PostgreSQL
* **PostgreSQL** — надежная реляционная база данных для хранения каталога товаров и профилей пользователей
* **JSON Web Tokens (JWT)** — стандарт для безопасной передачи информации между клиентом и сервером в виде токенов
* **Bcrypt.js** — библиотека для надежного хэширования паролей перед их сохранением в БД

## 🛡️ Безопасность и архитектура прав (RBAC)
Доступ к маршрутам (endpoints) динамически проверяется через кастомные функции-посредники (**middleware**). Доступные роли в системе:
* `user` (Обычный покупатель) — имеет право только просматривать каталог товаров.
* `admin` (Менеджер магазина) — имеет право просматривать каталог, добавлять новые товары и изменять существующие.
* `superadmin` (Главный администратор) — обладает абсолютными правами, включая полное удаление позиций из базы данных и управление ролями пользователей.

## 🛠️ Эндпоинты (Маршруты API)

### 🔑 Авторизация (Доступно всем)
* `POST /auth/register` — регистрация нового аккаунта (пароль автоматически хэшируется через `bcrypt`)
* `POST /auth/login` — аутентификация пользователя (сервер сверяет хэш и возвращает подписанный `JWT-токен`)

### 📦 Каталог товаров (Доступы защищены middleware)
* `GET /items` — получение списка всех товаров *(доступно всем)*
* `POST /addItem` — добавление нового товара в БД *(доступно только `admin`, `superadmin`)*
* `POST /change` — изменение параметров существующего товара *(доступно только `admin`, `superadmin`)*
* `DELETE /deleteItem` — полное удаление товара из базы данных *(доступно только `superadmin`)*

## 💻 Локальный запуск проекта

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```

2. Установите все зависимости проекта:
   ```bash
   npm install
   ```

3. Настройте конфигурацию окружения:
   Создайте файл `.env` в корне проекта и укажите ваши параметры подключения к PostgreSQL и секретный ключ для JWT:
   ```text
   JWT_SECRET=ваша_секретная_строка_для_шифрования_токенов
   ```

4. Запустите сервер:
   ```bash
   npm start
   ```

## 📬 Тестирование
Все маршруты бэкенда полностью протестированы и оптимизированы для работы через современный API-клиент **Bruno**. Запросы авторизации поддерживают передачу токена через заголовки `Authorization: Bearer <token>`.
